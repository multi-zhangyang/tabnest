# 隐私说明

TabNest 使用 `bookmarks` 权限读取与管理浏览器书签，使用 `storage` 保存偏好与本页打开书签的次数，使用 `favicon` 显示浏览器提供的网站图标。不申请浏览历史、全站读取或剪贴板读取权限。

书签数据保留在 Chrome；偏好与计数保留在扩展本地存储。开发预览使用当前站点的 localStorage，与真实浏览器书签隔离。为兼容旧版，首次读取可能迁移历史 Chrome sync 设置；新版不向 sync 写入。

常见网站图标随扩展打包；其他图标由 Chrome 图标服务提供。关闭“在线图标”时，扩展不会主动直接访问网站获取图标；开启后会请求对应网站的 `/favicon.ico`，使用不携带来源页面的 Referrer 策略。打开书签本身会正常访问相应网站。

没有分析 SDK、广告追踪、账号后端或远程遥测。JSON／HTML 导出由用户发起，生成本地下载文件；导入文件在浏览器内校验和处理，不上传到服务端。书签导出包含标题、网址与文件夹关系；完整备份额外包含热度、主题及界面设置。删除恢复记录仅保存在本机扩展存储中，保留最近 20 次操作、最多 4 MB；布局缓存、拼音索引与导入／恢复操作记录均在本地处理，不发送到服务器。HTML 使用纯解析器读取，不执行文件内脚本或加载远程资源。

卸载扩展会按 Chrome 的规则清除扩展存储，不会删除浏览器原有书签。扩展中执行的书签修改属于真实 Chrome 书签修改，是否同步到其他设备取决于 Chrome 自身设置。

## 2.7 最近打开

最近打开仅记录通过 TabNest 打开的有效网址和打开时间，在本地最多保存 50 条；不使用浏览历史权限，不读取其他页面的访问记录。搜索显示最多八个仍存在的书签。完整 JSON 备份可包含这些记录，普通书签导出不包含。布局快照是独立、可丢弃的本地缓存。所有功能免费，无账号、收费入口或遥测。

## 2.7.1 恢复文件

故障页的恢复导出只读取当前扩展可访问的书签树、原始存储文档、主题和已有恢复记录，生成本地文件，不上传数据，不触发迁移或写回。损坏和未知版本内容保留在文件中，导入时只恢复通过校验的部分。恢复文件包含私人网址，分享前应自行移除私人信息。
