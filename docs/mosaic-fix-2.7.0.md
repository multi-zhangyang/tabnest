# TabNest 2.7.0 布局与模式切换复验

日期：2026-10-01（持续复验至凌晨）。此记录对应连续拼图 v8、即时导航、按需搜索及最终单视图模式切换；首次升级的历史验收保留在 acceptance-2.7.0.md。全部功能免费，未新增权限或前端说明段落。

## 修正行为

- 拼图必须由连续切分树完整重建，保留整区覆盖和固定间距，修复热门卡片增长停滞及附近小卡片散落后留下空洞。区域最多 24 张；优先调整原边界，必要时只重新切分本区。点击目标面积不减，附近低热度卡片可缩到 56 × 56px Logo 方块，远处区域和画布高度保持。
- 按累计点击共同计算有上下限的热度份额，增长使用本次份额增量与最新累计份额，被挤小的热门卡片可以重新取得空间。初始化一次性拟合历史热度，撤掉按网址顺序的历史重放；共享边界必须有真实投影重叠，按邻接图距离与热度让位，达限后稳定。详见 [算法设计](heat-algorithm-2.7.0.md)。
- 旧有效 v8 缓存增加面积分配版本标记，缺少标记时首次打开按保留计数校正区域内部面积，固定区域外框，无热度区域不动；不清除数据，也不要求先点击。点击前后份额都被压在下限的冷门卡片仍请求受控增长，避免多个历史热点使冷门卡片前几次点击无变化。
- 初始化采用有限候选与最多 32 份不可变几何模板，点击后的局部求解保留完整候选。性能场景增加 80% 非零、0–4095 累计点击的确定性分布，不只测试首次安装的空计数。
- 最大面积与区域和缩放相关，标准缩放最高 520²，最长边最高 700px，长宽比不超过 2:1。共享 240ms 边界时间线；无法安全插值的重新切分只在透明中点应用有效矩形。连续点击衔接当前矩形和透明度，操作浮层与多选冻结后续热度变化。
- “书签拼图／文件夹”撤掉浏览器 View Transition 快照，使用单个实际内容树先淡出 90ms，透明时切换，有效布局准备好后淡入 150ms。切换期间固定高度，顶部不参与过渡；快速反向切换保持当前透明度。多选进入拼图允许完成首次有效计算，后续继续冻结，避免空画布锁住界面。
- 新标签页先确定主题，首屏就绪后一次淡入。搜索索引按需建立，计算 Worker 与搜索索引闲置 30 秒释放。当前页导航由 MV3 事件 Worker 继续保存计数和最近打开，页面立即跳转。

## 性能与内存

Windows 11，i7-11800H，32GB，Chrome 154；每场景 5 个独立页面，1440 × 900，未缓存布局，无 CPU／网络节流，测试运行器关闭 GPU。P95 为五个样本的最大值，数据来自最终实现的 artifacts/performance-check.json。

| 历史热度 | 20000 | 2000 | 2145ms | 88ms | 335ms | 368ms | 157 |

5000 条两种目录分布与历史热度场景均通过既有门槛：首屏 ≤1500ms，搜索／点击反馈 ≤100ms，首个面积变化 ≤150ms，挂载 ≤250。末尾内容的滚动及键盘可达性同时通过。历史热度场景包含 80% 非零、0–4095 次累计点击；20000 条历史热度首屏 P95 2145ms、首次面积变化 P95 368ms，高于 5000 条的目标值，本轮不宣称该极端场景达到同一门槛。

5000 条内存检查在强制 GC 后记录 V8 JavaScript 堆：启动页面约 13.24MB、Worker 0.99MB；首次搜索页面约 14.60MB、Worker 6.67MB；闲置后 Worker 为 0，下一次搜索重新建立索引。页面堆没有下降，不据此宣称总内存降低。这些数值不含浏览器 RSS、原生图像或 GPU 内存，原始数据见 artifacts/memory-check.json。

当前标签页的本地拦截目标导航实测 67ms，卸载后点击与最近打开记录正常保存；不代表真实网站的网络载入耗时。

## 交付

源代码、免费扩展 ZIP、SHA-256、动态拼图 GIF 与自动检查报告位于 artifacts。安装包体积和校验值由 tools/release.mjs 从同一次构建自动生成，唯一发布数据见 [发布报告](releases/2.7.0.md)。升级原解压目录后重新加载扩展，保留扩展身份与本地数据；v8 只重建可丢弃布局缓存。
