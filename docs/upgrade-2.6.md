# TabNest 2.6 本地升级验收

版本：2.6.0；日期：2026-09-28。保留原 Logo、热度云图／分区主导航和升级前已有修改；不接入账号、收费接口、后台或遥测。

## 实现结果

- 云图采用累计点击的对数权重与固定画布面积再分配；正方形、横向、纵向混排，48 × 48px 下限，图标／标题／域名自适应。零点击同权重，小规模集合增删复用分割关系，点击、刷新及重新打开保留布局记忆。
- 云图 240ms 共享边界过渡，点击反馈 160ms；菜单、弹窗、多选和拖动暂停进行中的边界动画并冻结后续几何计算。无持续背景动画，减少动态效果取消几何动画。
- 常见桌面宽度恢复三列分区；所有滚动条隐藏，保留原生滚动和键盘访问。全页面不添加教程或设计说明文字。
- Command 搜索面板、Ctrl K／⌘ K、中文／拼音／首字母、路径与多关键词，50 项书签预览与匹配总数，完整结果虚拟渲染。文件夹定位与操作入口共用面板，关闭恢复焦点和滚动。
- 重复网址按真实目录选择保留项，删除预览与恢复；协议、查询参数、片段保留区别。
- JSON v5 混排顺序、v2–v4 兼容、HTML 纯解析导入与导出、特殊协议保存／复制。导入异常项预检与跳过，统一新建目录写入。
- 最近删除按 20 次／4 MB 淘汰最旧记录，单次超限阻止普通删除，独立永久删除确认。操作中断留下本地记录，核对实际创建内容，不自动重放不确定步骤。
- 共享目录索引、分区内外两层虚拟渲染、千条以上本地 Worker，过时结果保护与后台搜索索引准备。

## 明确边界

Chrome 书签 API 与扩展存储之间没有原子事务，也无法阻止其他扩展在校验后立即修改数据。中断记录展示实际状态并交由用户核对，不声称自动恢复所有故障；原始 ID 与添加时间无法由 Chrome API 还原。

极端热度首先满足最小尺寸和可访问性，因此面积允许饱和；形状比例是受空间约束的偏好，不承诺任意数量、宽度和热度下固定的正方形数量。性能数据来自本机固定样本，不代表全部硬件。
