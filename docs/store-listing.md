# 商店发布材料

名称：TabNest — 书签导航新标签页

简介：书签拼图随使用频率生长，支持中文搜索、文件夹整理和本地备份。

TabNest 将浏览器书签呈现在新标签页。常用书签逐渐变大，附近卡片自动让出空间，每张卡片保留可点击的最小尺寸。文件夹视图直接管理浏览器真实目录。

支持中文、拼音、首字母搜索，最近打开，批量整理，重复书签检查，HTML 与 JSON 导入导出，删除恢复，以及亮暗主题。

所有功能免费，没有账号、广告和遥测。书签与偏好在本地处理。权限用途详见 [隐私说明](privacy.md)。

截图使用公开测试书签，由 `tools/docs-screenshots.mjs` 生成。当前材料不代表已经提交或通过商店审核。

截图提交文件位于 `store/screenshots/`，尺寸为 1280×800 PNG；包含亮暗拼图、文件夹、搜索与编辑界面。`metadata.json` 记录候选构建和公开样例来源。

动态面积演示：[dynamic-mosaic.gif](store/dynamic-mosaic.gif)。演示使用公开样例书签，构建编号和尺寸采样保存在同目录 JSON 文件。
