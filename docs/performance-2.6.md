# TabNest 2.6 系列性能记录

最新复测：2.6.1，2026-09-28。

本机独立临时 Chrome 配置，1440 × 900，关闭 GPU，不做 CPU／网络节流；每个场景五个新页面，清除布局缓存。首屏计时截至云图出现后的第二个绘制帧；搜索记录打开面板后的首次查询，热度记录点击至持久化计数更新。

设备：win32 10.0.26200；11th Gen Intel(R) Core(TM) i7-11800H @ 2.30GHz；16 个逻辑核心；32 GB 内存；Chrome/154.0.8037.57。

样本为可重复的中文标题与均匀目录分布；深层目录、低配机器、其他扩展和真实浏览器负载会影响结果。当前报告并非通用硬件承诺。详细五次原始样本见 `artifacts/performance-check.json`，运行 `npm run test:performance` 可复测。
