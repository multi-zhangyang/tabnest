# TabNest 2.7.0

本轮保留现有界面材质、顶部入口、隐藏滚动条与文件夹整理流程。所有功能免费，无新增权限、导航层级或解释性前端文字。

## 改动

- 设置面板使用 Dialog、Card、Tabs、ToggleGroup、Field、Switch、Slider、Badge 与 Separator 组合，固定高度，黑白语义主题，分类内容平滑过渡；导航、主题和弹窗统一动效，减少动态效果与首帧稳定继续保留。
- 新标签页先确定正确主题背景，预加载字体，首屏就绪后一次短淡入，避免导航、占位卡片与拼图分段闪现；不改变布局位置。
- “书签拼图／文件夹”使用单个实际内容树：90ms 淡出，在透明时切换，目标布局准备好后 150ms 淡入。撤掉产生重影的浏览器快照过渡；选中底座滑动，顶部位置和切换期间高度稳定。快速切换从当前透明度接续最新目标，慢计算不提前显示空拼图，旧 Chrome 使用同一路径，减少动态效果直接切换。
- 拼图卡片重做为白色／石墨灰哑光背景，细内边缘与中性图标底座；删除彩色背景、渐变和图案，保留品牌图标。鼠标点击不再播放外圈闪动，键盘焦点继续可见。
- 动态拼图以累计点击分配局部面积，最小 56 × 56px，仅显示 Logo。标准缩放最大面积按区域空间计算，最高 520²、最长边不超过 700px，长宽比不超过 2:1；小卡片连续趋向正方形。
- 每区最多 24 张书签。相邻卡片让位，区域外位置保持；点击不增加画布高度，达到边界后保留有效布局。
- 连续切分保持整区填满，修复内侧热门卡片过早停止增长和卡片缩小后留下空洞。优先调整既有边界，必要时重分本区，远处区域位置保持。
- 共同计算有上下限的累计热度份额，首次加载不再逐网址重放历史点击；单次点击结合份额增量与累计份额，被挤到 Logo 大小的热门卡片可重新取得空间。真实边界邻接优先，达限后停止微动，计数继续保存。完整公式与约束见 [算法设计](heat-algorithm-2.7.0.md)。
- 点击前后份额都在下限的冷门卡片仍请求受控增长；旧 v8 布局首次打开自动按累计热度校正内部面积，保留区域外框和所有数据，修复更新后仍保持旧尺寸的情况。
- 240ms 边界动画；不能安全插值的重新切分采用短淡出／淡入，透明中点切换有效矩形。连续点击衔接显示状态，菜单、弹窗和多选期间冻结，支持减少动态效果。
- v8 布局缓存保存切分及热度快照，四份与 4 MB 容量淘汰；旧缓存重新生成，书签和计数保留。
- 链接打开方式改为互斥选项；新安装默认前台新标签页，现有偏好及旧版缺字段行为保留。
- 搜索加入最近打开；排序遵循相关性、热度、最近时间、浏览器顺序，标题精确匹配优先。
- 最近打开使用独立本地文档与锁，辅助失败不阻止链接打开。完整 JSON 备份支持可选记录，保持 v2–v5 兼容。
- Worker 与页面共用算法、输入输出类型和版本检查，异常或超时回退；设置保存失败恢复确认状态。
- 新标签页按需准备搜索；闲置 30 秒释放搜索索引和计算 Worker。当前页打开由 MV3 事件 Worker 继续保存计数，页面立即导航，无新增权限。

## 验证与安装包

原升级结果见 [验收报告](acceptance-2.7.0.md)，后续背景重设计见 [界面复验](ui-surfaces-2.7.0.md)，本次布局与内存修正见 [修正复验](mosaic-fix-2.7.0.md)；体积和 SHA-256 由 [发布脚本](../tools/release.mjs) 从同一次报告自动生成到 [发布数据](releases/2.7.0.md)，不手工维护数值。

ZIP 解压后，在 Chrome 扩展管理页加载解压目录。升级已安装扩展时保留原扩展身份，重新加载即可；不要清除本地数据。首次升级会重建可丢弃的旧布局缓存。
